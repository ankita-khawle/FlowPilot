# FlowPilot Web

React + TypeScript + Vite frontend scaffold. The initial screen is a non-functional dashboard shell; workflow creation will be implemented in a later milestone.

## Run locally

```bash
npm install
npm run dev
```

The Vite development server proxies `/api` requests to `http://localhost:8080`. Start the Go API in a separate terminal.

## Checks

```bash
npm run build
npm test
```
